# 🚀 SkillBridge (MERN Stack Project)

SkillBridge is a role-based learning management system built using the MERN stack.
It allows institutions, trainers, and students to manage batches, sessions, and attendance efficiently.

## ⚙️ Features

### 👑 Institution

* Create batches
* View batches
* View sessions
* View attendance

### 👨‍🏫 Trainer

* Create batches
* Add students to batch
* Create sessions
* View attendance

### 👨‍🎓 Student

* View batches
* View sessions
* Mark attendance

### 📊 Programme Manager / 🛡️ Monitoring Officer

* View batches
* View sessions
* View attendance

---

## 🛠️ Tech Stack

* **Frontend:** React.js (Vite), Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT + Cookies

---

## ▶️ Run Locally

### 🔹 Backend

```bash
nodemon app.js
```

### 🔹 Frontend

```bash
npm run dev
```

---

## 🌐 Deployment

* **Frontend:** Netlify
* **Backend:** Render

## 📌 Notes

* Role-based access control is implemented
* Secure authentication using cookies
* CORS configured for cross-origin requests
